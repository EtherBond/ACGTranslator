# ACGTranslator v1.0.1 — 实验性快速接话增强
- 本地 WeSpeaker 边界核查；确认换人后分两段复核识别并逐条翻译。
- 关闭、未安装模型、模型故障或分析超预算时保留普通识别路径。
- 相邻两句在悬浮窗同时保留；历史及双语 SRT 独立记录。
- 修复短字幕被延长覆盖后续句子，以及识别结束时间超过音频长度的问题。
- 增加可下载/删除的接话模型，更新设置中的开关及状态。
- 不注册人物身份，不保存声纹；只处理当前片段，每片段最多一个边界。
这是实验性功能。英语合成样本的分段已验证，尚无真实日语动漫精度提升结论。
已有安装请运行 Setup.cmd 更新 Python 依赖，在模型管理下载 WeSpeaker 模型后保存设置。
发布包仍不包含 Python 环境和任何模型；首次初始化联网，之后离线运行。
