# ACGTranslator v1.0.2 — 接话提速、延迟统计与游戏采集

本版保留现有主模型，改善快速接话处理，并提供可查看、导出、清空的字幕阶段延迟统计。

## 更新内容

- 接话边界确认后，词级对齐可靠时直接拆分整句识别，减少半句重识别造成的漏字、重复与等待；不可靠时保留原回退。
- 声线计算增加适度 CPU 并行，复用特征配置、减少复制，候选和判断规则保持不变。
- 新增“延迟统计”：识别/翻译排队、处理耗时、控件更新、丢弃与失败；支持导出 JSON、清空，最多在内存保留 512 条阶段记录。
- 新增游戏日中双语 OCR 与连续录音采集、整理包和复核导出工具，支持没有配音的候选留待核验。
- 新增录音校准入口、回放验证和可选识别实验设置。采集器不会自行调用助手，程序不会自动训练或替换模型。

## 下载与升级

普通用户下载 **ACGTranslator-v1.0.2-win-x64.zip**。开发者可下载 **ACGTranslator-v1.0.2-source.zip**，或使用标签对应源码。SHA256SUMS.txt 提供附件校验值。

Windows 包内置 .NET 8 x64 运行时，**不含 Python、Python 依赖和模型权重**。首次安装 64 位 Python 3.10–3.13（建议 3.12），完整解压到可写目录，联网运行 Setup.cmd，再运行 Start.cmd。初始化完成后可使用已安装模型离线识别和翻译。

升级建议解压到新目录并重新建立 Python 环境；已有 models 可复制复用，`.venv` 不应直接跨目录搬运。用户设置和历史继续存放于 LocalAppData/ACGTranslator。游戏采集数据位于原安装目录的 data 下，需要单独保留。

游戏双语 OCR 需要 Windows 日语和简体中文 OCR 语言功能；普通实时翻译不依赖 OCR。快速接话增强需在模型管理下载 WeSpeaker 接话模型。

## 验证与限制

- 67 项 Python、56 项 .NET 测试通过；实际本地识别、翻译与隐藏 WPF 控件更新已验证。
- 本机 70 条开发录音、两轮反序对照：此次声线优化使完整识别总耗时减少约 **19.8%–21.7%**，逐条文本与分段边界一致。
- 提速来自更多 CPU 并行；独立声线测试中 CPU 总时间增加约 23%。不代表功耗降低，也不是所有设备或游戏场景的保证。
- 数据有模型筛选偏差，不宣称本次声线优化提高准确率。真实游戏运行下的端到端延迟仍需测量；统计中的句末由分段器估计，控件更新不等于显示器呈现。
- 语音分段、按需复核、保留上下文和微调工具仍为实验功能，原默认值不自动改变。更多说明见包内 docs 和 VALIDATION.md。
