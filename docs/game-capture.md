# 游戏训练素材采集器

2026-10-17 更新：默认流程改为 **采集 → 停止保存 → 助手整理 → 导出训练数据**。用户不需要逐条选择保留、修改文字或确认。原有编辑功能收在“高级：查看或手动编辑（可选）”中。

## 用户操作

1. 启动 `artifacts/capture-preview/start-capture.cmd`，或从主窗口进入“游戏采集”。也可运行 `ACGTranslator.App.exe --capture`。
2. 选择游戏窗口和输出设备，框选日文、中文及可选角色名。文字区域应覆盖完整的多行字幕。框选结果在分辨率不变时自动复用。
3. 先让游戏播放有声音的内容，点击“检查录音（5 秒）”。程序短暂切回游戏，返回后显示所选设备是否收到音频。无信号时检查游戏实际输出设备与选择是否一致。然后游戏显示日中双语字幕，开启自动播放，点击“开始采集并返回游戏”。返回采集器时画面取样暂停，连续录音仍然保留。
4. 点击“停止并保存”。程序保存原始记录并自动生成整理包，不要求逐条确认，也不按旧的确认/排除标记过滤。
5. 在当前助手对话中说“整理最新采集”即可交接；也可以点击“复制整理请求”，将包含本机路径的请求粘贴到对话中。**采集器不会自行唤醒或调用聊天助手。**

旧会话选择后点击“生成整理包”即可，既有素材无需重录。一个包包含该会话全部候选，过去排除的条目也交给助手重新判断。

## 保存的内容

原始数据仍在项目根目录的 `data/game-captures/<会话ID>/`，不随仓库分发。

- `capture.wav`：连续的 16 kHz 单声道 PCM16 录音，包括所选播放设备上的 BGM、音效和其他应用声音。
- `session.json`：全部字幕候选、估计时间范围、旧标记及警告。
- `frames/`：文字变化时的证据截图。新版本在字幕联合区域上下额外保留 80 像素、左右额外保留 64 像素（限制在游戏客户区内），尽量保留被 OCR 小选框漏掉的文字。画面发生变化时还会间隔约两秒补充证据帧；并非视频录制。
- `frame-index.jsonl`：新截图对应的时间、裁剪原点、大小和采集块编号。旧录制没有此文件不影响交接。
- `observations.jsonl`：逐次 OCR 文本、帧时间与截图索引，包含未形成稳定候选的中间文字。
- `audio-timing.jsonl`：录音回调与样本写入时间，用于分析音画偏差。
- `handoffs/<编号>/`：冻结的独立整理包，复制连续录音、全部截图与记录；以后修改会话不会覆盖旧包。

整理包的 `candidates.jsonl` 一律标为 `raw`、`verified_original:false`。`previous_review` 只保留历史标记，不作为过滤条件。`bundle.json` 最后写入，记录文件 SHA-256 和缺失文件；没有这个文件的目录是未完成导出，不能直接使用。素材复制失败不会删除已保存的原始会话，可重试。

整理包会额外占用接近原始录音与截图总大小的磁盘空间。用“打开数据目录”查看或清理旧包；“删除本会话”会连同原录音、截图及包一并删除，操作前有确认。

## 助手整理与训练导出

详细约定见 [助手整理流程](capture-assistant-workflow.md)。助手应先核对截图原文，再用录音与识别结果检查配音、边界和完整性。不要把识别模型的输出直接当作训练标准答案。

导出到独立目录，保留：

| 文件 | 内容 |
| --- | --- |
| `train.jsonl`、`audio/` | 已整理且有文本与音频核验依据的原文及切片 |
| `pending.jsonl` | 尚未处理或仍有疑点的候选，不参与训练 |
| `excluded.jsonl` | 确定排除的条目及原因 |
| `decisions.jsonl` | 助手逐条修正、保留/排除决定及依据 |
| `summary.json` | 数量、总时长、来源摘要；也表示导出完整结束 |

训练导出没有“至少三个场景”的限制。制作独立评测集时，应按录制/场景隔离，避免将重叠或邻近句子随机混入训练集与测试集。数据导出本身不训练模型，也不改变翻译器设置。

没有配音的句子保留为原始素材，但不作为有声识别的配对样本。不确定是否有配音、文字无法辨清或边界无法确定时，由助手标记为待处理，不要求用户逐条决定。缺失的声音或被截掉且无其他证据的文本不能靠推测补齐。

## 捕获限制

画面和音频通过 Stopwatch 与回调到达时间近似对齐。台词候选保留前 250 ms、后 150 ms；这不是精准音频边界，连续录音是后续重新切片的依据。

只截取前台游戏客户区；后台、最小化、分辨率变化、其他窗口遮挡可能导致画面缺失。游戏自动播放由用户开启。单次最多两小时，空间低于 512 MB 或发生录音/OCR 错误时停止或报错。OCR 仍可能漏字、错字，不作为已验证标签。

## 空录音保护（2026-10-17）

采集开始后，连续 30 秒始终没有任何能够写入 PCM16 的音频信号时，会停止并保存已有资料、恢复采集窗口并说明原因。实时状态显示是否收到信号及当前音量。正常录到信号后出现的短暂静音不触发启动保护。

`audio-timing.jsonl` 现在记录输入 RMS、转换后 RMS 和源格式；`audio-health.json` 保存信号统计并随整理包一并导出。这些统计仅区分有音频与空录，不证明一定有配音。

本机最新 641 条候选所在的约 56 分钟录音已确认全部采样为零，不能恢复为有声训练对。检查报告与排除记录保存在 本地 `data/training-datasets/<dataset>/`（不随仓库分发）；原始素材保留。新增保护通过 44 项 .NET 回归测试及隐藏界面/OCR/整理包验证。尚未进行真实游戏音频路由修复后的重采验证。
