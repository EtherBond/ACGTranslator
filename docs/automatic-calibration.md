# 识别自动校准（开发预览）

入口：翻译器主窗口的“自动校准”，或 `ACGTranslator.App.exe --calibrate`。本机预览可双击 `artifacts/capture-preview/start-calibration.cmd`。

导入你的游戏录音和对应的日文/英文原文，程序调用与实时翻译器相同的本地识别 worker，对比已安装配置，验证通过后自动保存设置并提供恢复入口。无需联网，不下载模型，不训练模型权重。

## 使用步骤

1. 停止实时识别，打开“自动校准”。从主窗口进入时会释放常驻识别和翻译模型；独立启动时应先退出正在运行的翻译器。
2. 选择一种素材格式：
   - **连续录音 + 原文 SRT**：一段 WAV/FLAC/OGG/MP3/OPUS 音频和一份 UTF-8 日文或英文 SRT。字幕起止时间对应实际配音，不能包含中文译文、说话人标签或排版标记；选择正确的 SRT 原文语言。程序按时间切片。整段录音可以超过 120 秒，每条语音须为 0.25–120 秒，字幕按时间排序且不能重叠。
   - **已复核清单**：选择“游戏采集”导出的 `verified.jsonl`，或同结构的 CSV/JSONL。可一次选择多个场景/会话的清单；清单模式不再额外选整段录音。相对音频路径相对于各自清单目录。
3. 核对文字、配音与时间对应关系，勾选确认。没有配音的旁白、只有 BGM 的句子不能作为有声识别的标准答案。程序能拒绝静音，不能可靠地自动判断 BGM 中是否有人声；错误 OCR 也必须先修正。
4. 选择“平衡 / 准确率优先 / 速度优先”和时间预算，点击“开始自动校准”。至少需要 **12 条已核验语音、3 个独立场景或时间块**。较多人物和场景的材料比最低数量更有代表性。
5. 验证通过且勾选自动应用时，保存获选识别配置。从主窗口进入的校准在返回后重新加载模型；独立校准后需重新启动翻译器。未通过、失败、取消或超时都不应用。
6. 在底部选择历史运行，查看报告或“恢复该次校准前设置”。取消自动应用可只生成报告。

只提供不带时间的整篇 TXT 暂不能直接校准；需要先配对语音片段或制作原文 SRT。中文字幕可辅助人工核对，不能代替识别用的日文/英文标准答案。

## 清单格式

每行一条 JSON；CSV 使用同名列。`id` 在所有导入文件中唯一，`scene` 是实际场景/采集会话，不能为了满足最低数量把相邻句子随意分组。

```json
{"id":"game-scene01-001","audio":"clips/001.wav","text":"今日はいい天気ですね。","language":"ja","scene":"scene01","game":"TenShiSouZou","verified_original":true}
```

一份采集会话通常只有一个场景，需要导入多个独立会话。SRT 模式自动按连续时间块分组；这只验证同一段录音内的表现，不能证明换游戏仍有同样提升。两种语言混合导入时，调参集和验证集都必须包含每种语言。

## 自动调整的范围

- 当前识别模型和本地已安装模型（最多 3 个模型路径）。不下载未安装模型。
- CPU / CUDA（已检测到 NVIDIA 显卡并安装对应运行库时）。按模型目录中的显存估算预留翻译模型和 1 GB 空间；不测游戏帧率，不能保证游戏满载时同样快。
- 解码搜索宽度 beam 1 / 2，保留当前 beam 5 配置作为基线（若当前使用它）。设置窗口也可手动恢复自动值 0 或选择 1 / 2 / 5。

保持原来的识别语言和快速接话增强设置参与比较。不会根据标准答案给识别器提示，也不会自动改翻译模型、切句长度、字幕外观或历史设置。中文翻译质量及真实播放时的切句效果不属于这次测试范围。

## 判断规则

1. 固定素材并保存音频摘要、模型/脚本摘要。重复音频和重复原文连接的场景合并，防止相同内容跨入调参集和验证集。
2. 大约 70% 的场景用于比较配置，其余只验证调参集选出的唯一优胜者；验证失败后不再换另一候选反复试同一验证集。每个分区至少 4 条、40 个原文字符。
3. 测字符错误率 CER，另对英语测词错误率 WER；统计 p95 识别耗时与实时率 RTF（总识别耗时 / 总音频时长）。RTF 必须不大于 1。验证集对基线和优胜者各运行两遍；少量样本仍可能受系统负载影响。
4. **平衡**：每种语言的错误率不能变差；CER 至少下降 1 个百分点且 p95 不增加超过 10%，或 p95 至少下降 10%。
5. **准确率优先**：每种语言的错误率不能变差；CER 至少下降 1 个百分点，或不降准且 p95 至少下降 10%。仍受 RTF 限制。
6. **速度优先**：p95 至少下降 10%，每种语言 CER（及英语 WER）最多增加 0.5 个百分点。

计时包含 worker 通信和识别，不包含模型启动、音频解码、中文翻译及最终字幕显示，因此不能当作端到端字幕延迟。模型加载、素材检查和哈希也需要时间；取消会结束子进程，不应用未完成结果。

## 结果与恢复

每次运行保存在项目根目录的 `data/calibration/日期-编号/`，已被 Git 忽略，不随仓库分发。

| 文件 | 用途 |
| --- | --- |
| `settings-before.json` | 开始前的设置备份，恢复时只还原识别模型、设备和 beam |
| `config.json` | 素材路径、模式及候选配置 |
| `dataset.jsonl`、`provenance.json` | 固定数据分区、音频/模型/脚本摘要 |
| `trials.json`、`tune-*` | 候选结果、逐句识别、错误率、worker 日志 |
| `holdout-*`、`report.json` | 独立验证结果与是否建议应用 |
| `planned-values.json`、`applied-values.json` | 应用计划与设置写入回执 |
| `cue-*.wav` | 从连续录音切出的片段（SRT 模式） |

脚本只生成建议；`report.json` 的 `settings_written:false` 描述脚本本身，是否由界面应用请看界面状态和回执。如果运行期间识别设置被其他窗口修改，界面拒绝覆盖。恢复时保留当前其他设置；被删除的模型需要先恢复才能还原对应配置。

可用“查看该次报告”打开目录，退出校准后在资源管理器删除不需要的运行目录进行清理。删除会同时失去该次报告、SRT 切片和恢复备份，不会删除源录音、源字幕或原清单引用的音频。

## 开发验证

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s scripts -p test_autotune.py
dotnet test tests/ACGTranslator.Tests/ACGTranslator.Tests.csproj
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/smoke_autotune.ps1 -RunFolder artifacts/autotune-validation/new-tts-run
dotnet run --project tests/ACGTranslator.CalibrationSmoke -- artifacts/autotune-validation/new-ui-run models/asr/whisper-base
```

合成语音冒烟使用 12 条 Windows 英语 TTS 和已安装 Whisper base，跑真实 worker、调参及独立验证，不写用户设置。界面冒烟在隔离目录验证应用、恢复、并发配置保护和 WPF 渲染。真实 galgame 的精度收益仍需用户提供已核验的录音与原文后测量；不把合成语音结果当作游戏提升证据。
