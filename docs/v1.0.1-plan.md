# ACGTranslator v1.0.1：快速接话增强
## 目标
快速接话时核查换人边界，分别识别、翻译、保存和导出，避免两人说的话粘成一句。
正常讲话保留原结果。不注册身份，不展示 A/B 标签，不保存声音特征或原始音频。
## 数据流
系统音频 → 现有分段 → Whisper 第一遍识别（增强开启时附词级时间戳）
→ 候选词边界两侧 WeSpeaker 特征比较 → 确认切换后分两段复核识别
→ 按时间顺序分别翻译 → 历史和双语 SRT。
不能只检测静音：候选包含无停顿的接话。不做全会话聚类，只保留当前 2～12 秒片段；
临时特征随请求释放，模型留在内存复用。跨片段已独立翻译的两句无需再次比较。
## 组件与预算
- WeSpeaker ResNet34-LM ONNX：26,530,309 字节；CPU 2 线程。
- 复用 ONNX Runtime，增加 kaldi-native-fbank 1.22.3。
- 官方模型固定 f0c48c298fd835726c27956a5d617bad7115627e，并校验 SHA256。
- 每片段最多 6 候选，按时间区间覆盖整个片段，区间内优先暂停位置。两侧至少各 0.8 秒，最多取 1.6 秒窗口，核查有效语音总量；比较余弦相似度并缩窗复核。
- 初始阈值：跨边界 < 0.35、同侧稳定性 >= 0.65；这是工程阈值，不是正确率。
- 650ms 分析软预算，单次推理不可中断；超预算放弃结果，跳过后续 3 段增强。
- 最多一个确认边界、两次额外 ASR；不递归。整体处理慢于音频时也进入冷却。
- 分段重识别失败或任一侧为空，保留完整初始结果，不丢字幕。
- 模型缺失普通识别；损坏/依赖失败提示并回退。预加载避免首次接话才加载。
- 音频回调不执行模型推理；普通讲话也有少量检测开销，不承诺零延迟。
## 设置与管理
提供增强开关、模型状态、模型下载/校验/删除。Python 依赖通过 Setup 更新。
保持 ISpeechRecognizer 多段返回接口，后续外部接入可复用；本版仅本地运行。
历史/导出继续使用独立字幕，保留准确时间，不把短字幕强制延长至 0.5 秒。
识别领先翻译时，按翻译完成顺序显示匹配的原文和中文，避免后续识别覆盖尚未展示的译文；分段后的两句一起保留。
## 验收
回归单段/多段顺序、相对到绝对时间、语言处理、历史和导出。
Python 测试同人/不同人/无间隔/短音频/预算耗尽/错误降级/关闭功能。
本地模型与 worker 冒烟、运行耗时、构建和可启动验证。
真实日语动漫和英语快速接话仍需人工标注对照 CER/WER、边界误检漏检及字幕延迟，
完成前以实验性功能发布，不宣称已提高准确率。
## 限制
极短回应、相似声线、情绪变化、音乐和重叠讲话可能失败。
本版没有音源分离，不能保证同时说话的两路内容均被识别。
每片段最多修正一个边界；更复杂对话待实测后扩展。
